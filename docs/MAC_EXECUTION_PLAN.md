# HARRY Translate V2 Mac 实施边界

## 目标

在 Apple Silicon Mac 上交付稳定、可复现、可回滚、可本地部署的实时同传
应用。质量顺序固定为：

1. 稳定性、可复现与数据安全；
2. 极速低延迟；
3. Mac 单窗显示层级、沉浸体验与语义精修。

## 平台边界

- Apple Silicon Mac；
- macOS 13 或更高；
- arm64 `.dmg`；
- 不包含其他平台启动器、音频后端、打包或测试对齐。

## 核心技术边界

| 领域 | 当前实现 |
| :--- | :--- |
| 音频 | 16 kHz、800 样本、1600 字节、50 ms；有界 Drop-Oldest 队列 |
| 会话 | 单一主字幕会话、单一活跃上游 Qwen WebSocket |
| 原生壳 | Tauri v2、一个 overlay、一个菜单栏托盘、可恢复穿透 |
| 全屏 | overlay 使用真实非激活 `NSPanel`，level 1000 |
| 热词 | 250 词、4096 B 默认预算、6144 B 硬上限 |
| 纠错 | 有界异步 worker、`source_hash` 乐观锁、零字幕标红 |
| 总结 | 默认关闭、有界队列、普通可关闭 WebView 窗口 |
| 持久化 | 配置和词库原子写；单会话 JSON 原子保存基础 |
| 计量 | 零 Token、零 `usage`、零费用、零账单字段 |
| 音效 | 零按键音、零提示音、零 `AudioContext` 发声 |

## 已实现阶段

项目已按 7 个 Phase、17 轮完成。最终正式标签为 `v2.0-mac-ready`。
各轮过程 handoff、阶段验收报告和历史代码地图已由用户归档到仓库外的
本地过程材料目录，不属于当前正式版输入。

活动仓库只保留：

- 当前正式源码；
- 可执行测试；
- 项目契约和 ADR；
- 开发与修复工作流；
- 正式 README、安装、教程、用户指南、架构和排障文档；
- 发布报告和第三方许可。

## 发布门禁

- Python 全量、核心回归、Ruff 和 compileall；
- 前端 TypeScript、Vitest、Vite 和依赖审计；
- Rust 单测和 custom-protocol build；
- Mock smoke；
- 长会话与 1000 卡片压测；
- 原生 overlay/summary 生命周期连续 5 次；
- 进程和窗口残留检查；
- Markdown 链接检查；
- gitleaks 和 Git 跟踪文件检查；
- 性能相对可信基线劣化不超过 3%。

不得跳过、弱化、缩规模或伪造上述证据。
